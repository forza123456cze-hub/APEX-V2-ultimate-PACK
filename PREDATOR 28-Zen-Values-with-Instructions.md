How to Load the Script onto Your Zen
Follow these steps using Zen Studio:



\-Open the Compiler tab in Zen Studio.
-Drag the script (.gpc file included) into the Compiler.
-Right-click the file and select Compile.
-Go to the Programmer tab.
-Click the icon with multiple horizontal lines to open your scripts list.
-Find your compiled script, then drag it into an empty slot.
-Click the Program button to save it to your Zen.

✅ Done! Your script is now loaded.

⚠ IMPORTANT
Vibration must be turned ON in-game for the script to work.
PS5 users must also have Adaptive Triggers in game enabled for Auto Detect to function.

\---

Navigation \& Controls:

Hold ADS + Tap Xbox/PS Button → Open Zen Main Menu (use D-Pad Left/Right to scroll).
Hold ADS + Tap Xbox/PS Button (in menu) → Save \& close menu.
Hold ADS + Tap Two Windows (Xbox) / Create Button (PS) → Turns off the script.

Setting up Values:

If using my values, set your Apex Legends sensitivity to 4-3 Linear, No Deadzone.
If using your own values, choose your settings (presets for each are available; ALC can be configured later).
If you don’t have PS5 Auto Detect, turn on Two Touch — you’ll be prompted to assign button combos to select guns manually (I use Left Stick Down + X, Y, B, A).

💡(Xbox/PC) — you can still enable Resync to auto-switch back to the correct gun after firing without needing ps5 roller.

\---

Changing Script Values:

Navigate to the Zen Main Menu.
Go to the Settings tab.
Set Stick Drift → 0

📌If using my values, set Target to Wall instead of Enemy. “Enemy” pulls aim too far down — “Wall” is more consistent.

Adjust Vertical and Horizontal recoil in setting menu for each gun (displayed as (edit vert, edit horiz) values below).
